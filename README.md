# Impact of Artificial Intelligence (AI) on Students

## Description

This is an end-to-end data analytics project designed to analyze how Artificial Intelligence (AI) tools affect students’ academic performance, learning habits, productivity, and overall educational experience.

The project uses data collection, cleaning, analysis, visualization, and reporting techniques to generate meaningful insights that help educational institutions understand the positive and negative effects of AI in education.

---

## Tools and Technologies Used

- MS SQL
- Python
- Pandas
- Seaborn
- Matplotlib
- Power BI

---

## Key Tasks Performed

- Cleaned and transformed raw Student AI Usage data using SQL Server Management Studio.
- Handled missing values and standardized column names.
- Performed SQL analysis to generate business insights.
- Conducted data analysis using Python libraries such as Pandas.
- Created visualizations using Seaborn and Matplotlib.
- Built an interactive Power BI dashboard for visualization.

---

## Key Insights

- Analyzed the average anxiety level of students during exams.
- Calculated Paid Subscribers Percentage:
  - Yes: 57.692%
  - No: 42.308%
- Identified the major category with the most paid subscribers.
- Found that Senior students had the highest average weekly AI usage with 8.46 hours.
- Analyzed Average Weekly GenAI Hours by Major Category.
- Studied the relationship between Skill Retention and Prompt Engineering Skills.
